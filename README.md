# Introductory Algorithms and Pseudocode Logic

Seminar coursework exercises prepared for Computer Programming and Algorithm Foundations at ASE Bucharest.

## Overview
This repository contains reference pseudocode solutions for foundational programming seminar problems, focusing on decision structures, numerical equations, and one-dimensional array manipulations.

## Implemented Algorithms
* 3-Number Ascending Sort: In-place variable swaps using conditional comparison branching.
* Quadratic Equation Solver: Real root determination for quadratic forms with comprehensive discriminant edge-case handling and first-degree fallback branches.
* Array Peak and Frequency Locator: Computes the maximum value within an array and outputs all corresponding index occurrences.
* Array Amplitude: Evaluates element dispersion by locating extreme values in an array and computing their absolute range.
* Polynomial Evaluation: Calculates polynomial values for a given evaluation point across sequential coefficient powers.
* Sorted Vector Insertion: In-place position search and element shifting to insert a new value while preserving ascending or descending ordering.
